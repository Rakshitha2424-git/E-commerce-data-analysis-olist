# Olist E-Commerce Data Analysis

An end-to-end Data Analytics project using the Brazilian Olist e-commerce dataset to analyze sales, customers, products, sellers, and delivery performance.

The project combines **Python, SQL, and Power BI** to transform raw e-commerce data into meaningful business insights.

---

## 📌 Project Objective

The objective of this project is to analyze Olist's e-commerce data and answer business questions such as:

- How does revenue change over time?
- Which product categories generate the most revenue?
- Which sellers generate the highest revenue?
- Who are the highest-spending customers?
- Which customers make repeat purchases?
- How long does delivery usually take?
- What percentage of orders are delivered late?
- How do customers rate their purchases?
